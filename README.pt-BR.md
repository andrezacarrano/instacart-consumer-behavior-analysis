# Análise de Comportamento do Consumidor - Instacart

## Objetivo do Projeto
O objetivo deste projeto é analisar o comportamento dos consumidores na plataforma Instacart, uma plataforma de entrega de supermercado. O problema de negócio a ser resolvido envolve entender padrões de compra, como horários de pedidos, dias da semana mais movimentados, produtos mais populares, frequência de reordenação e outros insights que podem ajudar a otimizar operações, marketing e experiência do usuário.

## Resultado
A análise exploratória dos dados revelou vários insights sobre o comportamento dos consumidores:
- O dia da semana com mais pedidos é o domingo (0 no dataset).
- A hora do dia com mais pedidos é por volta das 10-11 da manhã.
- O departamento com mais produtos pedidos é o de "produce" (produtos frescos).
- Os 20 produtos mais pedidos incluem itens como bananas, leite, ovos e frutas.
- Em média, as pessoas compram cerca de 10 itens por pedido.
- Produtos como bananas e leite são os mais reordenados.
- O tempo médio entre pedidos é de aproximadamente 11 dias.
- Identificamos e removemos duplicatas e valores ausentes, garantindo a qualidade dos dados para análises precisas.

## Ferramentas Utilizadas
- **Bibliotecas Python**: Pandas para manipulação de dados, NumPy para operações numéricas, Matplotlib para visualizações.
- **Tecnologias**: Jupyter Notebook para desenvolvimento interativo, CSV para armazenamento de dados.
